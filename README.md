# 🎮 BiteBoard Game

A 2-player Java chocolate board game.

## 🧱 Classes
- BiteBoardGame → Main class
- BiteBoardGameModel → Game logic
- BiteBoardGUI → GUI window
- BiteBoardPanel → Draws board & handles clicks
